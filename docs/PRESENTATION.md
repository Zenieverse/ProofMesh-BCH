
# Presentation Outline: ProofMesh BCH
## Bliss 2025 Hackathon

### Slide 1: Title
- **ProofMesh BCH**
- *Modular Smart Contract Playground*
- **Tagline**: "Building DeFi on Bitcoin Cash shouldn't require Assembly."

### Slide 2: The Problem
- BCH upgrades (PMv3, Cashtokens) are powerful but complex.
- Developers struggle to visualize UTXO data flows.
- Writing CashScript from scratch is error-prone.

### Slide 3: The Solution
- **Visual Builder**: Drag-and-drop interface.
- **Logic-First**: Focus on *what* the contract does (Escrow, Mint), not *how* to write opcode.
- **AI-Assisted**: Gemini audits your flow before you deploy.

### Slide 4: Technical Innovation (PMv3)
- **Introspection**: Contracts check their own inputs/outputs.
- **Cashtokens**: Native token handling inside the visual graph.
- **Covenants**: Enforcing spending paths visually (Edge = Transaction).

### Slide 5: Demo Flow
1. Connect Paytaca Wallet.
2. Drag "Prediction Market" node.
3. Set Oracle Public Key.
4. Click "AI Audit" -> Returns "Safe".
5. Deploy -> View TXID on Explorer.

### Slide 6: Market Potential
- Prediction Markets (without central servers).
- Event Ticketing (NFTs).
- DAO Treasuries (Multi-sig Vaults).

### Slide 7: Roadmap & Conclusion
- Q2: Mainnet.
- Q3: Community Template Marketplace.
